#  Sales Data Analysis Dashboard

A Power BI dashboard analyzing sales performance across cities from **2020 to 2024**.

---

##  What's Inside

| Visual | Description |
|--------|-------------|
|  Sales by City | Geographic map showing order distribution across 15 cities |
|  Sales Trend | Time-series chart tracking monthly sales from 2020–2024 |
|  Profit vs Net Sales | Scatter plot revealing the profit-to-sales relationship |
|  Discount by Promotion | Bar chart comparing average discounts across 5 promotion types |
|  Top/Bottom Products | Rankings by Sales, Quantity, and Profit |
|  Order Detail Table | Filterable transaction-level data with customer & product info |

---

##  Key Metrics

- **Total Orders:** 3,510
- **Total Sales:** 122M (full period)
- **Total Profit:** 12.9M
- **Total Quantity Sold:** 7,100+ units

---

##  Highlights

- **Best Selling Product:** Apple iPhone 14 (21.4M in sales)
- **Highest Profit Product:** Apple iPhone 14 (2.25M profit)
- **Top Promotion:** Weekend Flash Sale (avg. discount 23K)
- **Peak Sales Year:** 2023 (0.65M spike)

---

##  Built With

- Power BI Desktop
- Data includes: Orders, Customers, Products, Promotions (2020–2024)

---

##  Filters Available

- Date Range (dual filter for period comparison)
- Customer Name
- Product Name
- Promotion Name
